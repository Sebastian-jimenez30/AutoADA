Buscar Keys (archivo)

Ayuda — Buscar Keys desde archivo

Esta modalidad procesa un archivo Excel con múltiples keys para automatizar la búsqueda en SCADA, HSH y ODS. Usa la misma lógica que la aplicación de escritorio, generando el reporte Find_Key.xlsx.

Requisitos del archivo

  • Formato .xlsx, .xlsm o .xls.
  • Las keys deben estar en la columna A; la primera fila se considera encabezado y se omite.
  • Se permiten comodines con % y códigos de 8 dígitos (ej. 12345.67).

Flujo

  • Opcionalmente actualiza los datasets remotos (SCADA/HSH/ODS) antes de buscar.
  • Ejecuta scripts.buscar_keys reutilizando la lógica de AutoADA.
  • Genera el mismo reporte que Buscar Key, disponible para descarga y vista rápida.

Parámetros de búsqueda

Tip: asegúrate de que la primera fila sea un encabezado (ej. Key) y coloca las claves a partir de la fila 2.
