Buscar Key

Ayuda — Buscar Key

Esta herramienta te permite localizar una o varias keys dentro de los datasets más recientes.

Entradas

  • Empresa: selecciona la empresa objetivo.
  • Dominio: define el entorno de origen (SCADA, HSH, ODS, etc.).
  • Actualizar información: si está activado, se ejecutarán los procesos importar_all y convertir_all antes de buscar.
  • Key(s) a buscar: admite múltiples keys separadas por comas. Puedes usar el símbolo % como comodín.

Salidas

  • Genera el archivo Find_Key.xlsx con las coincidencias encontradas.
  • Registra la ejecución y resultados en la consola del proceso.

Restricciones

  • No permite ejecutar búsquedas simultáneas.
  • No modifica datos en los sistemas origen.
  • Requiere conexión estable al entorno ODBC configurado.
