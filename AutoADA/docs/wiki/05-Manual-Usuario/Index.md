# 05 – Manual de Usuario (GUI)

Esta sección es un **manual práctico** para usuarias y usuarios de AutoADA. Explica, paso a paso, cómo usar cada pantalla de la interfaz gráfica:

- Qué hace cada módulo.
- Qué datos se necesitan antes de empezar.
- Qué botones hay que usar y en qué orden.
- Dónde se generan los resultados.
- Qué hacer cuando aparece un error.

Si necesitas saber “qué scripts corren por detrás”, revisa también la sección de **Flujos funcionales**; aquí nos enfocamos en el *uso*.
