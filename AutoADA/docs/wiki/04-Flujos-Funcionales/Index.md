# 04 – Flujos funcionales / Pipelines

Esta sección describe, de forma operativa y técnica, los **pipelines principales** de AutoADA:

- Qué problema resuelve cada flujo.
- Qué entradas necesita (datos locales, archivos, parámetros en la UI).
- Qué pasos se ejecutan internamente (importar, convertir, scripts CLI).
- Qué salidas genera (archivos, carpetas, logs).
- Cómo interpretar resultados y errores comunes.
